# 4일차: 가구 등록·이동·회전

작성일: 2026-11-13 (한국 시간)

## 구현 범위

- 침대·책상·옷장·소파·테이블 프리셋을 선택하고 이름·가로·세로 크기를 입력.
- 기본형 및 사선·곡선 자유형 평면도에서 미리보기 → 위치 클릭 → 가구 배치 확정.
- 배치한 가구를 마우스/터치로 드래그 이동, 좌표는 1cm 단위.
- 선택한 가구의 이름·크기·중심 좌표 수정, 각도 입력 또는 90도 회전, 삭제. 화면 밖으로 이동한 가구도 좌표 입력으로 복구 가능.
- 가구 간 겹침과 벽 밖 배치를 빨간색/목록 오류로 표시.
- 잘못된 신규 배치는 확정 불가. 기존 가구 이동 후 오류는 표시하고 계속 수정 가능.
- 자유형 방 반전 시 가구 중심·각도를 함께 반전. 기본형 방은 투영 변환으로 함께 반전.
- 문·창문 배치 도구와 가구/꼭짓점 이동이 동시에 작동하지 않도록 입력 경로 분리.
- 예시 방/형태 변경 시 가구도 초기화하며 미리 안내.

## 계산과 제한

가구는 회전 가능한 직사각형으로 모델링합니다. 가구 겹침은 분리축(SAT) 검사로 판정하고 맞닿기만 하는 경우는 허용합니다. 방 경계 검사는 꼭짓점뿐 아니라 가구 변의 교차 구간도 검사하여 ㄱ자/ㄷ자 방의 파인 부분을 가로지르는 배치를 잡습니다. 곡선 벽은 기존의 64구간 근사 경계를 사용합니다.

가구 크기는 10~1,000cm, 중심 좌표는 ±2,000cm 범위입니다. 문 개폐 궤적·통로 폭·벽장 높이·창문 간섭은 검사하지 않습니다. 데이터는 페이지 내 상태로만 유지되며 새로고침 시 초기화됩니다.

## 검증 상태

Codex 실행 환경이 시작에 실패했으나 GitHub Actions의 Node 22 환경에서 npm ci 및 npm run verify를 실행했습니다. 최초 구현은 ESLint·테스트·TypeScript·프로덕션 빌드·HTTP smoke 검사를 통과했습니다. 독립 JavaScript 실행에서도 기하 계산 9개를 확인했습니다. 최종 커밋의 자동 검사 상태는 PR에서 확인할 수 있습니다.\n\n실제 브라우저 조작 검증과 Sites 웹 배포는 실행 환경 장애로 미완료입니다. 배포 웹은 이전 3일차 기능을 유지합니다.

환경 복구 후 roomfit-ai 폴더에서 npm ci, npm run verify를 실행하고 브라우저에서 미리보기·확정·드래그·회전·삭제·반전 및 기존 문/창문 회귀를 확인해야 합니다.
