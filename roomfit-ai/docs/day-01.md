## 범위 결정

- 앱 이름: RoomFit AI
- 핵심 대상: 방의 기존 가구를 재배치하거나 새 가구를 추가하려는 사용자
- MVP: 수동 치수 입력 기반 2D 평면도와 가구 배치·추천
- 1일차 제외: OpenAI API 연동, DB, 로그인, 실제 방 편집, 3D
- 후속 확장: 사진·스캔 분석 및 3D 미리보기
- 현재 내 방 만들기 링크는 준비 화면으로 이동하며 입력·저장을 지원하지 않음
