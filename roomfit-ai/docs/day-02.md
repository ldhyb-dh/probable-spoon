# 2일차: 방 치수 입력과 2D 평면도

작성일: 2026-11-12 (한국 시간)

## 구현

- /room/new 준비 화면을 가로·세로 입력 폼으로 교체.
- cm 단위 정수 100~2,000만 허용하고 빈 값·범위 초과·소수·비정상 값에 오류 표시.
- 잘못된 입력 제출 시 첫 오류 필드에 포커스. 이전에 만든 유효한 평면도는 유지.
- 제출하면 가로/세로 비율을 유지하는 SVG 외곽선과 치수, m 및 m² 단위 요약 표시.
- 360 × 420cm 예시 방 버튼, 입력 변경 시 업데이트 안내.
- 모바일에서는 입력과 평면도를 세로로 배치.
- 홈 화면의 기능 설명을 실제 구현 범위로 갱신.

100~2,000cm 정수 제한은 초기 버전의 구현 기준입니다. 실제 측정은 벽 안쪽 길이를 사용합니다.

## 검증

- npm run verify 성공: ESLint, 테스트 3개, Next.js 빌드, TypeScript, 서버 HTTP smoke 검사.
- 정상 치수와 양 끝 경계값, 양 축의 잘못된 값, 극단적인 가로·세로 비율 및 캔버스 경계를 검사.
- 서버에서 / 및 /room/new HTTP 200, 없는 경로 404, 빌드 CSS 응답 확인.
- 공개 웹 주소는 기존 비공개 접근 설정을 유지해 갱신. 공유 브라우저에서는 로그인 안내까지만 확인되므로 입력·클릭·모바일 시각 검증 완료로 표시하지 않음.

## 직접 확인

1. 웹에서 내 방 만들기 클릭.
2. 360, 420 입력 후 평면도 만들기 클릭 → 3.6m × 4.2m, 15.12m² 확인.
3. 가로를 500으로 바꾸고 업데이트 → 5m × 4.2m, 21.00m² 확인.
4. 빈 값·0·99·2001·소수 입력 시 오류 안내 확인.
5. 예시 방으로 시작하기 클릭 → 360 × 420 복원 확인.

## 현재 한계와 다음 단계

직사각형 방만 지원하며 데이터 저장은 아직 없습니다. 새로고침 시 입력이 초기화됩니다. 사진 인식·자동 실측·AI 추천은 이번 단계에 포함하지 않았습니다. 다음 단계는 문·창문의 벽 위치와 폭 입력입니다.
