# 문·창문 아이콘 직접 배치와 미리보기

작성일: 2026-11-13 (한국 시간)

## 사용자 흐름

1. 방을 생성한 후 평면도 위의 문/창문 아이콘 선택.
2. 벽 가까이 마우스를 옮기면 가장 가까운 벽에 맞춰 반투명 미리보기 표시.
3. 초록색은 배치 가능, 빨간색은 겹침·폭 초과·곡선 문 등 배치 불가 상태.
4. 클릭/터치하면 위치가 고정되지만 아직 목록에 추가되지 않음.
5. 폭·경첩·열림 방향을 조절한 후 배치 확정을 눌러야 저장된 페이지 상태에 추가.
6. 다른 위치를 클릭하여 다시 선택하거나 취소/Esc로 중단.
7. 목록의 수정은 기존 배치를 유지한 상태에서 미리보기로 편집. 확정해야 교체되며 취소하면 기존 배치 복구.

기존 숫자 입력 후 문·창문 추가 버튼을 누르는 양식은 제거했습니다. 폭/경첩/열림 방향만 도구 모드에서 조절하며 벽과 시작 거리는 선택한 위치에서 계산합니다. 수정 버튼을 누르면 평면도 도구로 스크롤합니다.

## 기술 동작

포인터를 SVG 좌표로 변환한 뒤 투영된 벽까지 거리를 계산합니다. 화면상 24px 안쪽의 가장 가까운 벽을 선택하고 문·창문 중앙을 포인터 위치에 맞춥니다. 폭 전체가 벽 범위 안에 들어가도록 시작 거리를 제한합니다. 곡선 벽은 128구간 근사로 가장 가까운 위치와 벽을 따른 거리를 계산합니다.

벽을 반전하거나 화면 크기가 달라져도 현재 투영 함수를 사용합니다. 자유형에서 배치 도구가 활성화된 동안 꼭짓점 드래그는 시작하지 않으므로 두 조작이 충돌하지 않습니다.

미리보기는 확정된 문·창문 배열과 별도 상태로 관리합니다. 벽/예시 방을 변경하거나 꼭짓점을 추가/삭제하면 진행 중 배치를 취소합니다. 이미 확정한 항목의 기존 검증·재배치 규칙은 유지됩니다.

## 검증

npm run verify 통과: 계산 테스트 총 21개, ESLint, 빌드, TypeScript, 서버 경로·CSS 응답.
신규 테스트는 직선/사선 벽 위치 찾기, 중앙 맞춤, 벽 끝 제한, 먼 포인터 거부, 반전·축소된 좌표, 곡선과 곡선 끝 근처의 유효 배치를 검사합니다.

실제 브라우저에서의 마우스·터치 시각 검증은 미리보기 환경 제한으로 완료하지 못했습니다. 배포는 기존 본인 전용 웹 주소에 반영합니다. 데이터는 페이지 내 상태로 유지되어 새로고침하면 초기화됩니다.
