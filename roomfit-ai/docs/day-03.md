# 3일차: 문·창문 배치

작성일: 2026-11-13 (한국 시간)

앞서 정한 1주차 순서에서 방 크기·평면도 다음 단계인 문·창문 입력을 구현했습니다.

## 기능

- 기본형 /room/new 및 자유형 /room/custom의 평면도 아래에 문·창문 편집기 추가.
- 벽 선택, 벽 시작점부터 거리, 폭을 cm로 입력하여 추가·수정·삭제.
- 문은 경첩(시작/끝)과 열림 방향(방 안/밖)을 선택하고 개방선과 회전 궤적 표시.
- 문은 직선·사선 벽에, 창문은 직선·사선·곡선 벽에 배치.
- 폭 10cm 이상, 시작 거리 0 이상 검증. 벽 끝 초과, 같은 벽의 다른 문·창문과 중첩 거부.
- 기본 방의 상하/좌우 반전 및 자유형 좌표 반전 시 문·창문을 함께 반전.
- 벽 치수나 꼭짓점 변경 후 맞지 않는 배치는 자동 삭제하지 않고 목록에 재배치 안내. 잘못된 항목은 그림에서 숨김.
- 꼭짓점 추가/삭제로 직접 바뀐 벽의 문·창문은 벽 미지정 상태로 보존하고 다시 지정하도록 안내. 나머지 벽 번호는 재연결.
- 예시 방 불러오기/기본 형태 변경 시 문·창문 초기화.

## 계산

곡선 창문의 시작 거리와 폭은 벽을 따라 잰 거리입니다. 전체 벽 길이는 기존 수치 적분을 사용하고, 거리→곡선 파라미터는 128구간 표로 근사합니다. 창문 표시는 17개 점을 이어 표현합니다. 문·창문이 있어도 방 바닥 면적과 전체 외곽 둘레는 변하지 않습니다.

곡선 벽에 직선 문을 끼워 넣는 모델은 제공하지 않습니다. 문 열림 표시는 참고용이며, 다른 벽이나 가구와 문짝의 충돌을 검사하는 기능은 이후 단계입니다.

## 검증

기하 계산 테스트 19개 통과. 신규 테스트는 문/창문 범위와 중첩, 사선 문 길이·경첩·열림 방향, 곡선 창문의 거리 위치, 반전 후 부착 위치, 벽 추가/삭제 시 부착 정보 보존을 확인합니다.

프로덕션 빌드·TypeScript·ESLint 및 HTTP smoke 검사로 기존 화면 경로와 새 편집 화면 소스 구성을 검증합니다. 실제 브라우저 조작 검증은 미리보기 도구의 Next.js 실행 옵션 제한으로 남아 있습니다.

## 직접 확인

1. 내 방 만들기에서 예시 방 생성.
2. 평면도 아래 문·창문 배치에서 벽 A, 시작 거리 20cm, 폭 80cm의 문 추가.
3. 경첩/열림 방향을 바꿔 문 수정.
4. 같은 벽에 겹치는 창문 추가 시 오류 확인.
5. 다른 벽에 창문을 추가하고 반전 버튼으로 함께 반전되는지 확인.
6. 자유형 곡선 방에서 곡선 벽에 창문 추가. 곡선 벽에 문 추가 시 안내 확인.
7. 문·창문 삭제 및 벽 길이 축소 후 재배치 안내 확인.

현재 데이터는 페이지 내 상태로 유지되며 새로고침/다른 편집 화면으로 이동 시 초기화됩니다. 저장·불러오기, 가구 등록·배치는 이후 단계입니다.
