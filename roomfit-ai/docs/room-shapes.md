# 방 형태 확장

작성일: 2026-11-12 (한국 시간)

## 입력 방식

직사각형 외에 ㄱ자(6개 벽), ㄷ자(8개 벽)를 지원합니다. 각 형태의 참고도에 A~H 벽 표기를 표시하고, 입력 필드에서 어떤 벽을 측정하는지 안내합니다.

- 직사각형: 전체 가로 A, 전체 세로 B.
- ㄱ자: 전체 가로 A, 전체 세로 F, 들어간 가로 C, 들어간 세로 D.
- ㄷ자: 전체 가로 G, 전체 세로 H, 들어간 가로 C, 들어간 세로 B, 왼쪽 날개 A.

생략한 벽은 선택한 직각 형태의 닫힌 경계를 만족하도록 자동 계산합니다. 둘레의 총합만으로는 방의 모양이나 면적을 정할 수 없으므로 총둘레를 단독 입력받지는 않습니다. 예를 들어 전체 400×500cm 직사각형과 오른쪽 아래 180×200cm를 뺀 ㄱ자 방은 둘레가 모두 18m이지만 면적은 각각 20m²와 16.4m²입니다.

## 평면도와 검증

- SVG polygon으로 실제 방 경계를 표시하고 모든 벽 길이를 목록으로 제공.
- 다각형 꼭짓점으로 면적을 계산하고 모든 벽 길이의 합으로 둘레를 계산.
- 전체 길이는 100~2,000cm, 추가 길이는 10~2,000cm 정수.
- 들어간 폭/깊이는 전체 폭/깊이보다 작아야 함.
- ㄷ자의 왼쪽 날개와 들어간 가로 합은 전체 가로보다 작아야 함.
- 잘못된 입력은 평면도에 반영하지 않고 오류 필드로 포커스.
- 형태 변경 시 이전 평면도는 지우되 입력 수치는 유지.

## 확인 결과

npm run verify 통과: ESLint, 테스트 5개, 프로덕션 빌드, TypeScript, HTTP smoke 검사.
테스트는 형태별 벽 수·면적·둘레, 같은 둘레의 서로 다른 모양, 잘못된 치수와 경계값, 잘림 구간 충돌, 표시 비율을 검증합니다.
브라우저 상호작용·시각 검증은 공유 브라우저 로그인 제한으로 완료했다고 표시하지 않습니다.
