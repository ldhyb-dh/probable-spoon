# 사선·곡선 벽 편집

작성일: 2026-11-12 (한국 시간)

## 사용 방법

내 방 만들기 → 사선·곡선 벽 직접 그리기 또는 /room/custom 접속.

1. 사선 방 또는 곡선 방 예시 선택.
2. 그림의 점이나 번호 버튼으로 꼭짓점을 선택.
3. 그림의 꼭짓점을 마우스/터치로 끌거나 X·Y 좌표를 입력하여 위치 변경. 이웃한 두 점의 방향이 가로나 세로가 아니면 사선 벽.
4. 선택한 꼭짓점에서 다음 점으로 이어지는 벽의 휘어짐을 입력하거나 슬라이더로 조절.
5. 직선 벽에서는 꼭짓점을 중간에 추가 가능. 곡선 벽은 휘어짐을 0으로 바꾼 뒤 추가.
6. 꼭짓점 삭제 시 이전 벽을 새 다음 점까지 직선으로 연결.

방의 한 곳을 원점으로 정하며 X+는 오른쪽, Y+는 아래쪽입니다. 좌표는 ±2,000cm, 휘어짐은 ±500cm, 꼭짓점은 3~12개입니다. 마지막 점은 첫 점으로 자동 연결됩니다.

## 곡선과 계산

곡선은 양 끝점과 중앙 휘어짐으로 정의한 2차 베지어 곡선입니다. 원호나 원형 벽과 정확히 같지는 않습니다. 중앙점의 벽 진행방향 오른쪽 편차가 양수이며, 음수는 반대 방향입니다.

직선·사선은 유클리드 거리, 곡선 길이는 도함수의 크기를 적응형 Simpson 수치 적분하여 계산합니다. 면적은 경계 선적분으로 계산합니다. 화면의 곡선은 동일한 제어점을 사용하는 SVG Q 명령으로 표현합니다.

벽 교차·겹침 검사는 곡선당 64개 선분으로 근사합니다. 매우 작은 곡선 교차나 접점은 놓칠 수 있으며 시공용 정밀 도면이 아닌 공간 계획용 개략도입니다. 잘못된 입력 또는 교차가 감지되면 면적·둘레 계산 결과를 숨기고 오류를 표시합니다.

## 검증

npm run verify 통과: ESLint, 테스트 총 11개, 프로덕션 빌드, TypeScript, HTTP smoke 검사.

추가 테스트: 사선 길이·면적, 곡선 중앙점·면적 증가분, 독립적인 10,000구간 길이 근사와 비교, 경계 진행방향 반전, 잘못된 입력·자기교차·겹친 벽·되돌아가는 벽, 곡선이 맞은편 벽을 가로지르는 경우.

/room/custom HTTP 200 및 편집 화면 문구 확인. 실제 브라우저의 클릭·시각 검증은 기존 로그인/실행 환경 제한으로 미완료입니다.

## 유지 범위

기존 직사각형·ㄱ자·ㄷ자 입력을 유지합니다. 저장 기능은 아직 없어 새로고침 시 초기화됩니다. 문·창문·가구·사진 인식·AI 추천은 이번 변경에 포함하지 않았습니다.


## 마우스 이동 및 반전 추가

- 포인터 캡처를 사용하므로 점 밖으로 마우스가 나가도 이동을 이어갑니다.
- 이동 시작 시 배율/오프셋을 고정하며 이동 중 화면 맞춤을 다시 계산하지 않습니다.
- 이동량은 SVG의 실제 화면 변환 행렬로 계산해 화면 크기·여백의 영향을 반영합니다.
- 좌표는 1cm 단위, ±2,000cm로 제한하며 인접 꼭짓점과 같은 위치는 허용하지 않습니다.
- 놓은 위치에서 벽 교차가 검출되거나 이동이 취소되면 이동 전 좌표로 복구합니다.
- 자유형 평면도는 좌표 자체를 반전하고 곡선의 휘어짐 부호도 바꿉니다. 동일한 반전을 두 번 하면 원래 형상으로 돌아옵니다.
- 기본 방 형태 화면에도 상하·좌우 반전 버튼을 제공합니다. 템플릿의 벽 번호와 길이는 유지됩니다.
- 계산 테스트 총 13개, 빌드·타입 검사·서버 응답 검증 통과. 새 테스트는 반전 전후 곡선 샘플 좌표·면적·둘레와 드래그 좌표 제한을 확인합니다.
- 실제 브라우저 드래그 시각 확인은 미완료입니다. 미리보기 도구가 Next.js에 지원되지 않는 --host/--strictPort 옵션을 전달하여 시작하지 못했습니다.
