# 5일차 작업 기록

정확한 원래 일일 계획을 확인할 수 없어 현재 단계의 다음 기능으로 저장과 불러오기를 구현했습니다.

- 직사각형·ㄱ자·ㄷ자 기본형과 사선·곡선 자유형을 각각 이름을 붙여 저장하고 불러옵니다. 방 형태, 확정한 문·창문과 가구, 기본형 반전 상태가 포함됩니다.
- 저장은 이 기기의 이 브라우저에만 보관됩니다. 자동 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. 확정하지 않은 미리보기는 저장하지 않습니다.
- 의자, 냉장고, 싱크대, 책장, 서랍장, 신발장, 행거, TV·거치대, 식탁, 조리대·가스레인지, 세탁기, 전자레인지, 직접 입력을 추가해 기존 5종과 함께 18종을 제공합니다. 가구 기본 크기는 예시이므로 실제 치수로 수정해야 합니다.
- 저장된 데이터의 형식이 맞지 않으면 덮어쓰지 않고 안내합니다. 이름을 지정해 최대 50개까지 저장할 수 있습니다.
- 검증: ESLint, 자동 테스트 35개, 프로덕션 빌드, TypeScript, HTTP smoke 검사 통과. 실제 브라우저에서 예시 방에 의자를 배치하고 저장한 뒤 새로고침해 다시 불러오는 과정을 확인했습니다.
- AI 추천, 사진 분석, 3D 및 계정 간 동기화는 아직 구현하지 않았습니다.
